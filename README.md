# AI Host – RVCE CSE

Starter rebuild of the AI Host event controller based on the recovered project concept and the supplied agenda image.

## Run
Open `index.html` directly in a modern browser.

## Current features
- RVCE CSE AI Host dashboard
- 12 agenda items from the supplied agenda
- Click an agenda item to load its announcement
- Browser text-to-speech
- English / Tamil / Hindi language selection when browser voices are available
- Voice selection
- Speech rate and pitch
- Speak / Pause / Resume / Stop
- Live clock
- Responsive UI
